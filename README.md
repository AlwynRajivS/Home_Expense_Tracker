# 💰 NDR Finova – Login Based Home Finance Management System

## 📘 Project Description

NDR Finova is a secure login-based home finance management web application used to track income, expenses, transfers, balances, analytics, and reports.

The system provides a clean dashboard, graphical reports, and export options to monitor financial activities easily.

This project is designed for personal finance tracking with modern UI and cloud support.

---

## ✨ Features

- 🔐 Secure login access
- 💵 Income / Expense tracking
- 🏦 Cash & Bank balance
- 📊 Dashboard summary
- 📅 Date filter
- 📋 Transaction history
- 📈 Analytics charts
- 📤 Export reports
- 🌙 Dark mode
- ⚙ Settings panel
- 📱 Responsive design
